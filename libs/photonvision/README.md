# PhotonVision local Maven repository

Version: `v2026.3.4`

Source: [official PhotonVision offline release](https://github.com/PhotonVision/photonvision/releases/download/v2026.3.4/photonlib-v2026.3.4.zip)

This directory contains the two Java artifacts and the Java runtime JNI artifacts for every platform declared by the PhotonVision vendordep. C++ development artifacts are omitted because this is a Java project. Every included artifact was verified against the SHA-256 checksum in the official archive.
